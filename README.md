# BeliefTrace public information

Static, public-only website for the BeliefTrace iPhone app. The app is in preparation; this repository contains no application backend, private corpus, credentials, customer content, or review contact.

Run `python3 build.py` and `python3 validate.py`. GitHub Actions publishes the `dist` artifact to GitHub Pages. All routes are real static files under `/belieftrace/`.

Operator and support facts were carried forward from existing BeliefTrace public-information records. Apple review contact is deliberately excluded. The app icon is an existing BeliefTrace brand asset. This site does not use a decorative graph or simulated app screenshots. Verified current native imagery remains a release requirement.

The release is not publicly available. `release.json` records the selected US offer of $4.99/week for 25 successful answers. The app and subscription remain in preparation until the signed candidate and release gates are complete. Any publication is information and support, not a claim of Apple approval.
